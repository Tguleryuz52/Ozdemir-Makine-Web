# design/references — Tasarım Referansları

Buraya tasarım girdilerini koy; bunlardan design token sistemi + tasarım yönü çıkarılır.

## Ne koyacaksın
1. **Framer'dan beğendiğin site** — ekran görüntüleri (PNG/JPG) + link (`LINKS.md`).
2. **Mevcut ozdemirmakine.com.tr** — ekran görüntüleri + link.
3. İlham veren diğer örnekler (opsiyonel).

## Nasıl
- Görselleri direkt bu klasöre at (örn. `framer-hero.png`, `mevcut-anasayfa.png`).
- Linkleri `LINKS.md`'ye yaz (her satır: link + kısa not — neyi beğendin?).

## Sonra
Referanslar gelince: layout ritmi, tipografi, renk, boşluk, bileşen kalıpları analiz edilip
`design/design-system.md` token'ları kilitlenir → shotgun (3-5 yön) → mockup → build.
