# Faz 2 · Plan 01 — Design System

## Amaç
himon analizinden (`design/references/himon-analysis.md`) çıkan tasarım dilini + Özdemir
mavisini resmî bir **token kontratına** dönüştür ve `globals.css`'e kilitle. Bundan sonra
her bölüm bu tokenlardan beslenecek; ham renk/sihirli değer yasak.

## Kapsam
- **Var:** renk rolleri, tipografi ölçeği, spacing ritmi, radius, motion token'ları, doküman.
- **Yok:** sayfa/bölüm build'i (Faz 3+), logo entegrasyonu (Talha atacak), animasyon bileşenleri.

## Bağlam (kilitli kararlar)
- Aksan: Özdemir mavisi `#234D9C` (derin `#164295`, parlak `#0E92DD`).
- İskelet: ink `#0E0E0E` + paper `#F2F0EC` + beyaz, tek aksan.
- Font: Geist (display 500, tight) + Geist Mono (kicker) + Geist 400 (body). Kurulu.
- Kurulum kısıtı: **sadece npm/npx/node** (IT sistem-installer engeli). Yeni paket gerekmiyor.

## Görevler

### T1 — `design/design-system.md` token kontratı
Yaz: renk rolleri (ground/ink/brand/muted/border/accent + dark), tipografi ölçeği
(display-xl/lg, h1-h4, kicker, body-lg/base/sm — Geist boyut/ağırlık/tracking/lh), spacing
skalası (bölüm ritmi), radius skalası (kart/pill), motion (easing eğrileri + süreler),
gölge/kenarlık. himon ölçüleriyle referanslı.

### T2 — `globals.css` renk token'ları
shadcn token'larını Özdemir paletine bağla: `--primary` = brand mavi, `--ring` = brand,
`--background`/`--foreground` ink/paper rolleri, dark bölümler için ground token'ları.
Mevcut oklch nötr yapıyı bozmadan brand rollerini oturt.

### T3 — Tipografi ölçeği
`@theme`'e display/heading/body boyut + tracking + line-height token'ları. Geist ağırlıkları
(500 display, 400 body) `next/font`'ta doğru yüklensin (gerekirse `weight` ekle).

### T4 — Spacing, radius, motion
Bölüm dikey ritmi (section padding ölçeği), radius (kart ~16-24px, pill full), motion
token'ları (`--ease-out-soft`, süreler) `@theme`/`:root`'a.

### T5 — Doğrulama sayfası (geçici)
`/design-system` rotasında token'ları gösteren geçici bir referans sayfası (renk swatch'ları,
tipografi ölçeği, buton varyantları). Faz sonunda kaldırılır/işaretlenir.

## Doğrulama (bu plan biterse şunlar DOĞRU olmalı)
1. `design/design-system.md` tüm token gruplarıyla dolu, himon referanslı.
2. `globals.css`'te brand rolleri + tipografi/spacing/radius/motion token'ları tanımlı.
3. `/design-system` sayfası token'ları doğru render ediyor (mavi aksan, Geist ölçeği).
4. `npx tsc --noEmit` temiz · `npx eslint` temiz · `npm run build` hatasız.
5. Ham default Tailwind rengi veya sihirli boşluk değeri yok (token üzerinden).

## Notlar
- Shotgun (3-5 yön): aksan + font zaten kilitli olduğundan design-system'de tek yön.
  Görsel yön varyasyonları hero/bölüm tasarımında (Faz 3-4) mockup ile denenecek.
- Header taslağı (`src/components/layout/header.tsx`) bu tokenları zaten kullanıyor;
  Faz 3'te resmî planla cilalanacak.
