# design/inbox/ — Talha'nın attığı ham görseller (GIT DIŞI)

Talha buraya referans/logo/ekran görüntüsü atar. Ben buradan okurum.

**Akış:** Talha dosyayı buraya bırakır → ben okurum → karar `design/design-system.md` veya
`design/references/*-analysis.md` içine yazılır → ham dosya burada kalır, repoya girmez.

Kalıcı referans olacaksa `design/references/<kaynak>/` altına isimlendirilerek taşınır.
